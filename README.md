# Тижневе меню

Особистий PWA-застосунок без реєстрації: меню на 4 тижні під КБЖУ, рецепти з домашніми мірками, дві заготовки на тиждень і спільний список покупок. Оформлення за Kvitka Design System: graphite / wine / rose, шрифт Golos Text, логотип-квітка. Тема темна, а якщо на телефоні увімкнено світлу — кремова.

Адреса: **https://ikvitka2010-bit.github.io/weekly-menu/**

## Що вміє

- **4 тижні меню по колу:** Класика, По-домашньому, Турецький, Затишний. Червоне м'ясо й риба — раз на тиждень, лору не більше 1 кг на двох.
- **День закупки на вибір** (Налаштування → День закупки). За замовчуванням субота. Заготовка 1 — того ж вечора, заготовка 2 — через 3 дні (для суботи це вівторок, теж базарний день). Дати, дні, плани заготовок і підписи «на сб, вт» перераховуються самі.
- **Перемішати.** Через 4 тижні з'являється кнопка «Перемішати». Вона також є в налаштуваннях. Міняє порядок тижнів, днів усередині заготовки, сніданків і перекусів, але враховує терміни зберігання: риба йде наступного дня, печінка свіжа. Якщо тиждень уже почався, нове перемішування стартує з наступної закупки.
- **Нове меню кожні 4 тижні.** Автозавдання Claude складає 4 нові тижні й заливає сюди. Застосунок підхоплює їх сам і показує «Нове меню на 4 тижні!».
- **Свої КБЖУ:** цілі Б/Ж/В/ккал, розмір порцій (70–150 %, кнопка «Підібрати під мої ккал»), кількість людей. Мірки в рецептах і список покупок перераховуються.
- **Список покупок рахується з меню автоматично,** на потрібну кількість людей. Окремим блоком іде «Якщо в морозилці немає…».
- **Поділитися:** кнопка відкриває Telegram, WhatsApp, Нотатки тощо з невідміченими продуктами.
- **Спільний живий список:** галочки бачать обидва телефони (через безкоштовний Firebase, див. нижче).
- Працює без інтернету після першого відкриття.

## Встановлення на телефон

- **iPhone (Safari):** відкрийте адресу → «Поділитися» → «На екран „Додому“».
- **Android (Chrome):** відкрийте адресу → меню ⋮ → «Встановити застосунок».

## Спільний список (Firebase, один раз ≈5 хвилин)

1. Відкрийте [console.firebase.google.com](https://console.firebase.google.com), увійдіть з Google → **Create a project** → назва `weekly-menu` → Google Analytics вимкніть.
2. Зліва **Build → Realtime Database → Create database** → регіон **Belgium (europe-west1)** → **Start in locked mode**.
3. Вкладка **Rules** → замініть усе на правила нижче → **Publish**:

   ```json
   {
     "rules": {
       ".read": false,
       ".write": false,
       "lists": {
         "$code": {
           ".read": "$code.length >= 18",
           ".write": "$code.length >= 18"
         }
       }
     }
   }
   ```

4. Скопіюйте адресу бази вгорі вкладки Data (вигляду `https://weekly-menu-xxxx-default-rtdb.europe-west1.firebasedatabase.app`).
5. У застосунку: **Налаштування → Спільний список** → вставте адресу → **Створити спільний список**.
6. **Запросити другий телефон** → надішліть посилання. Друга людина відкриває його, і список підключається.
   На iPhone застосунок з головного екрана має окреме сховище, тож після встановлення відкрийте **Налаштування → «Або вставте посилання-запрошення»** і вставте те саме посилання.

Код списку довгий і випадковий, тож список бачать лише ті, у кого є посилання.

## Як влаштовано

| Файл | Що всередині |
|---|---|
| `index.html`, `styles.css` | розмітка й кольори Kvitka DS |
| `app.js` | екрани, розклад, перемішування, покупки, синхронізація |
| `menu-data.json` | **згенерований** файл з меню. Руками не правити |
| `tools/source.json` | джерело меню: страви (грами на 1 порцію) і 4 тижні |
| `tools/catalog.py` | продукти: назви UA/TR, категорія, БЖВ на 100 г, домашні мірки |
| `tools/build.py` | рахує БЖВ, перевіряє правила, пише `menu-data.json` |
| `tools/tune.py` | підганяє грами під цілі БЖВ |
| `tools/NEW_CYCLE.md` | інструкція для Claude, як складати новий цикл |
| `sw.js` | офлайн-режим (після змін збільшуйте `VERSION`) |

Змінити меню: правите `tools/source.json` → `python3 tools/build.py` (перевірка правил і запис) → у `sw.js` збільшуєте `VERSION` → commit і push.
