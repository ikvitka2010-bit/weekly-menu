# Тижневе меню

Особистий PWA-застосунок без реєстрації: меню на тиждень під БЖВ, рецепти з домашніми мірками, дві заготовки і список покупок на двох. Оформлення за Kvitka Design System: graphite / wine / rose, шрифт Golos Text, логотип-квітка. Темна тема, а якщо на телефоні увімкнено світлу — кремова.

## Файли

| Файл | Що всередині |
|---|---|
| `index.html` | розмітка і нижня навігація |
| `styles.css` | кольори Kvitka DS, темна і світла теми |
| `app.js` | екрани, мірки, БЖВ, збереження галочок |
| `menu-data.json` | страви, меню, заготовки, покупки (щоб змінити меню, правте тільки цей файл) |
| `sw.js` | офлайн-режим |
| `manifest.webmanifest`, `icons/` | назва та іконка на головному екрані |

## Як опублікувати (GitHub Pages, безкоштовно)

1. На github.com створіть новий репозиторій, наприклад `weekly-menu` (Public).
2. **Add file → Upload files**, перетягніть **вміст** цієї папки (не саму папку): `index.html` має лежати в корені. Натисніть Commit.
3. **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
4. За 1–2 хвилини застосунок відкриється за адресою `https://<ваш-логін>.github.io/weekly-menu/`.

## Як встановити на телефон

- **iPhone (Safari):** відкрийте посилання → кнопка «Поділитися» → «На екран „Додому“».
- **Android (Chrome):** відкрийте посилання → меню ⋮ → «Встановити застосунок» / «Додати на головний екран».

Після першого відкриття застосунок працює й без інтернету.

## Як оновити меню

Змініть `menu-data.json` і в `sw.js` збільште `VERSION` (наприклад, `menu-v2`), щоб телефони підхопили оновлення. Галочки зберігаються лише на конкретному телефоні.

Перевірити локально: `npx http-server .` у цій папці. Відкривати `index.html` подвійним кліком не вийде: браузер не дасть завантажити `menu-data.json`.
